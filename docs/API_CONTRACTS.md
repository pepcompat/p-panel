# pPanel — API Contracts (v1)

Status legend per endpoint: `IMPLEMENTED` (with test id) / `PROPOSED`. Owners update this file when they implement.
This file is the **coordination contract** between `apps/api`, `apps/web`, `apps/agent` and (later) `apps/mcp`.

## 0. Conventions (COMPATTANA standard — mandatory)

- Base path: `/api/v1`. Center API listens on `:4000` (dev). Web on `:3100`. Agent mTLS gateway on `:4443`.
- Request JSON, camelCase body keys, omit null keys. Headers: `Authorization: Bearer <access>`, `X-Request-ID: <uuid>` (generated by server if absent and echoed back), `X-Client-Version`.
- Success: `{ "success": true, "statusCode": 0, "message": "ok", "data": <T>, "meta": { "requestId": "<uuid>" } }`
- List: same + `data: T[]` and sibling `"paginate": { "page": 1, "limit": 20, "total": 42 }`.
- Error: `{ "error": { "code": "STRING_CODE", "message": "human text", "details": <object|array|undefined> }, "meta": { "requestId": "<uuid>" } }`
- HTTP: 200 read/update, 201 create, 202 queued job, 204 no content, 400, 401, 403, 404, 409 conflict/version, 422 validation, 429, 500.
- Query: `page` (1), `limit` (20, 1–100), `sort` (createdAt), `order` (desc), `q`, filters `field[op]=value` with snake_case field names.
- Timestamps ISO-8601 UTC. IDs: UUID v7 strings. Enums are lowercase snake strings.
- DB: snake_case tables/columns via Prisma `@@map`/`@map`.
- Secrets never appear in responses or logs. Secret-bearing fields are returned as `{ "ref": "sec_...", "set": true }`.
- Every mutating endpoint writes an `audit_events` row (actor, action, target, result, requestId, diffHash).
- Writes on versioned resources accept `If-Match: <version>` → 409 `VERSION_CONFLICT` on mismatch.

## 5. Jobs (typed, P2)

Center side `IMPLEMENTED` (P2-T01, P2-T02, P2-T03-lite; jobs.spec). POST body: `{ type, params, ttlSec? (30–86400, default 600), desiredVersion? }`; 202/200 `data` = `{ jobId, status, job }`.

`Job = { id, serverId, type, params, status: queued|leased|running|succeeded|failed|expired|cancelled, idempotencyKey, expiresAt, leaseUntil, attempt, desiredVersion, actorId, correlationId, result, createdAt, updatedAt }`
Allowed `type` values (allowlist, typed params validated with Zod on Center **and** Go on agent):

- `inventory.collect` `{}` — read-only
- `discovery.scan` `{ sources: ["nginx","docker","systemd","php-fpm","ports"] }` — read-only
- `service.restart` `{ unit: string }` — unit must be in server's owned-resource allowlist
- `nginx.validate` `{ revisionId }`, `nginx.apply` `{ revisionId, expectedChecksum }` (P3)
  POST returns 202 `{ jobId, status: "queued" }`. Same `idempotencyKey` (header `Idempotency-Key`) → returns the existing job, 200.

### 6.4 Drift (P3-T05)

On each scan ingest, compare each file's sha256 with the previous scan and with `nginxFiles[].lastKnownSha256`. Differences not explained by an `applied`/`reverted` pPanel revision ⇒ `drift[]` entry `changedBy:"external"`, application `flags.driftDetected=true`, and any `draft|valid|approved` revision touching that file → `drift_blocked`. Creating or applying revisions on a drift-flagged app → 409 `DRIFT_REVIEW_REQUIRED` until `POST /applications/:id/drift/acknowledge` (perm `nginx.write`, records the new checksums as accepted baseline, audited). · `IMPLEMENTED` (P3-T05 Center side)

### 7.2 Secrets (P4-T02)

- Ticket: 32 random bytes base64url, stored as sha256, TTL 30 s, single use (atomic consume bound to `sessionId`). `wsUrl` = `PPANEL_PUBLIC_API_URL` with `ws(s)://…/api/v1/ssh/stream` — **never** carries the ticket.
- `GET /api/v1/ssh/stream` (upgrade handled on the API HTTP server, `ws` `noServer`, `maxPayload` 64 KiB, no compression): `Origin` must be in `WEB_ORIGIN` (missing/foreign → HTTP 403 before the upgrade, audited); any query string → 400; first frame within 5 s must be text `{ type: 'auth', ticket, sessionId }` → else close 4401. Then the Center re-checks user/role/grant/endpoint/limits/credential/trusted key, connects (ssh2 default algorithms, `readyTimeout` 10 s, SSH + TCP keepalive, no agent, no forwarding, no X11), opens a `shell` with PTY `xterm-256color` and sends `{ type: 'ready', sessionId, hostKeyFingerprint, endpoint: { path, host, port }, sshUser }`.
- Client → Center: binary = stdin; text `{ type: 'resize', cols, rows }`, `{ type: 'ping' }`, `{ type: 'close' }`; anything else → 4400. Center → client: binary = stdout/stderr; text `ready`, `pong`, `{ type: 'exit', code, signal? }`, `{ type: 'closing', reason }`, `{ type: 'error', code, message }`.
- Timers: idle `SSH_IDLE_TIMEOUT_SEC` (900; no stdin and no stdout), max `min(grant expiry, SSH_MAX_SESSION_SEC=28800)`, WebSocket ping 20 s (dead peer → close). Backpressure: SSH stream paused while `bufferedAmount > 1 MiB`.
- Close codes: 1000 normal, 1001 Center shutdown, 4400 protocol, 4401 auth, 4403 forbidden (grant/credential/terminated/auth refused by sshd), 4408 idle/max/expired, 4409 host key, 4429 limit, 4500 internal/connect failed. Every close ends the SSH channel and connection; the row gets `status` (`closed`, or `failed` when it never opened), `end_reason`, `bytes_in/out`, `exit_code`.
- `end_reason`: `client_closed | server_closed | idle_timeout | max_duration | grant_expired | grant_revoked | credential_revoked | host_key_mismatch | auth_failed | connect_failed | center_shutdown | center_restart | limit | terminated` (`terminated` is an API addition for the terminate route).
- Limits: `SSH_MAX_SESSIONS_PER_USER=3`, `SSH_MAX_SESSIONS_PER_SERVER=5`, `SSH_MAX_SESSIONS_GLOBAL=50` (open + pending-with-live-ticket), checked at POST and again at connect (WS 4429).
- Center shutdown closes live sessions `center_shutdown`; startup closes every `pending/open` row `center_restart`.
- `Server` adds `ssh: { endpoints: [{ path, host, port }], trustedHostKey, hasCredential }` (additive).
